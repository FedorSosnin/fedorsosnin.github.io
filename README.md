# fedorsosnin.github.io

Old addresses of [Catch 151](https://github.com/FedorSosnin/Catch151) (first called PokeKnomiGochi) that still answer
after the repo was renamed on 2026-11-13:

- `PokeKnomiGochi/update.json` and `PokeKnomiGochi/firmware/`: a frozen copy of the Knomi's 2.2.0 update, for Knomis that
  still check the old address (firmware doesn't follow redirects). 2.2.0 checks the new address from then on.
- Everything else under `/PokeKnomiGochi/` (the web installer, the Catch 151 Dex) forwards to the same page under
  `/Catch151/` (`404.html`).
